# 连续制片工作流

连续对话中按需读取本文件。它用于维护会话默认、空间连续性、分镜计时、长镜头、粤语对白、前景遮挡和复杂动作，不替代模型适配规则。

## 个人工作流默认值

除非用户在当前镜头明确覆盖，否则使用以下默认：

- prompt 正文用英文；解释可用用户当前语言。
- 台词保留用户原文，不翻译、不润色、不统一繁简。
- 未指定运镜时，使用轻微手持晃动与自然摄影师惯性。
- 每条最终 prompt 必须包含固定摄影规格：浅景深、大光圈、电影感与电影感散景、真实光学镜头眩光、薄雾状耀光、自然光晕溢出、8K 高帧率、真实胶片质感、细腻有机颗粒、35mm、哈苏式自然色彩分离与柔和高光过渡。
- 当前镜头明确要求长焦、鱼眼或其他焦段时，以当前要求为准，并将固定规格中的 `35mm` 写成 `authentic 35mm film-stock texture`。
- 无背景音乐，只保留同步现场音效与自然环境声。

用户以后再次修改这些默认值时，以最新明确声明为准。

## 空间连续性预检

写 prompt 前先在内部确定：

1. 镜头在人物的前、后、左、右、上或下。
2. 镜头朝上坡、下坡、入口还是来路。
3. 每个人物位于高处还是低处，谁更靠近入口。
4. 人流是朝镜头、背离镜头还是横穿；用户指定单向流动时，让所有行人保持同一方向。
5. 人物动作从哪一级台阶、道路哪一侧或画面哪一层开始，最终停在哪里。
6. 前景、中景、背景分别由谁占据，谁负责遮挡，关键动作和口型何时必须可见。

把最容易生成错误的 2–4 个空间事实直接写进 prompt。不要仅写“保持空间关系”。

## 人群、遮挡与碰撞

- 写清人群密度、速度、统一方向和面对镜头的正反面。
- 前景遮挡要写明来源；遮挡短暂经过画面，并为关键台词、手部动作和终点保留清楚可见的窗口。
- 碰撞按力的传递写：接触点 → 肩颈或躯干反应 → 重心变化 → 脚步补偿 → 可见终点。
- 用户指定“一步”时只写一步；指定被人群架着或推着时，说明支撑位置、脚是否仍触地，以及最终越过哪条线或到达哪一级台阶。

## 表演拆解

不要只写情绪标签。将表演写成按时间发生的可见变化：

1. 眼神接收与重新聚焦。
2. 上下眼睑、眉心或眉毛的轻微变化。
3. 呼吸停顿、吸气或呼气。
4. 嘴唇、下颌、颈肩张力。
5. 头部角度、重心或手部落点。

强情绪仍保持克制。用户要求多段递进时，用秒数或阶段锚点分配，例如 `0–1.5s urgency`、`1.5–3s confusion`，并给出可停住的最终表情。

## 精细手部动作

精细动作按可见机械顺序写，不用“完成某事”一笔带过。例如鞋带：

1. 先清楚显示已经系好的结。
2. 手指抓住哪一端，环如何收缩并退出。
3. 完全拆开后的状态。
4. 交叉、收紧、形成双环、再次系好的过程。
5. 手停在哪里作为终点。

需要观众看见的决定性动作应处于无遮挡、连续可读的画面窗口中。

## 长镜头与遮挡转场

- 写明唯一连续的摄影路径：起始景别与机位 → 运镜方向与角度 → 半径或距离变化 → 结束景别与构图。
- `180°` 完成半圈并停在对侧；`360°` 完成整圈并说明终点。
- 使用人物身体、肩膀、衣料或经过的前景物完全遮住镜头时，可在遮挡期间完成环境变化；遮挡前后人物位置、身体朝向和摄影机运动必须连续。
- 环境恢复或人群出现应从画面边缘和空间纵深逐步涌入，避免同一帧集体弹出。
- 长镜头内可包含一个自然的两拍变化，并保持摄影路径连续可追踪。

## 多镜头计时

用户要求分镜、合并多个镜头或给出多个景别时：

- 先按动作承载量分镜，再分配足够的对白和表演时间。
- 合并到一个 prompt 时使用明确时间轴：

```text
SHOT 1 — 0.0–4.0 seconds
...
CUT at exactly 4.0 seconds.
SHOT 2 — 4.0–9.0 seconds
...
```

- 总时长必须等于各段之和。
- 用户要求一镜到底时不得使用上述 `CUT` 结构。

## 粤语对白

- 原样复制用户提供的字形、标点、数字、语气词和停顿，不统一成繁体、简体或书面语。
- 明确说话者与 `authentic native Hong Kong Cantonese`，并描述急促、克制、疑问或公共广播等声音状态。
- 人物嘴部可见时绑定嘴唇、下颌、脸颊、呼吸与台词；嘴部不可见时写成明确的画外声，不声称可见口型同步。
- 不给用户没有提供的台词、翻译或罗马音；只有用户要求发音提示时才添加。

## 写实特效边界

真人写实镜头可以包含幽灵、发光或半透明效果，但要写成实拍可融合的光学效果。人物保持完整衣着与清楚外轮廓；透明度优先限制在外缘、光晕或投影层，不描述内部解剖结构。儿童或婴儿保持完整遮盖与安全支撑，特效不改变其身体结构。
