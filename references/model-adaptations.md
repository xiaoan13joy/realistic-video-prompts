# 模型适配指南

只读取并应用当前模型对应章节。模型能力可能随版本变化；若用户给出更具体的版本规则，以用户要求为准。

## Seedance 2.0（即梦 / 字节）

- 使用结构化长提示词，可明确拆成“镜头1、镜头2……”的多镜头序列。
- 在每个镜头内写入焦段、大光圈和浅景深。
- 参考图是主体、外貌、服装、环境、光线和氛围的唯一依据；不在提示词中复述这些静态内容。
- 真人写实任务必须加入“真人实拍摄影、真实皮肤纹理、自然光、浅景深、大光圈”，并按 [真人皮肤质感限定](photoreal-skin.md) 控制皮肤细节。
- 特写与近景完整写入 SSS 耳鼻暖透感、毛孔微纹理、仅 T 区微油、绒毛与微汗；中景至少选择两项；远景不要写不可见的毛孔级细节。
- 使用 45° 柔和侧主光与轻微逆光呈现皮肤层次，并在负面提示词中排除蜡像、塑料、磨皮、3D 渲染和全脸油光。
- 重点写动作、表演、运镜、画面中可见元素的动态、变化过程与镜头衔接。
- 每个镜头都使用明确运镜；定机位只在必要时使用，并保留克制的手持微晃。
- 建议顺序：镜头与运镜 → 可选前景或特殊构图 → 按五官、头颈、躯干和四肢拆解动作 → 人景融合 → 无音乐与同步音效。
- 避免同一时间给人物安排互相冲突的动作，保持多镜头人物与场景连续性。

## 可灵 Kling

- 使用简洁、连贯的自然语言，优先一段话讲清动作表演、画面内动态和运镜。
- 在镜头描述中明确“大光圈、浅景深”，但避免无必要地堆叠摄影参数。
- 不复述参考图已确定的人物、外貌、服装、环境、光线、色调和氛围。
- 默认使用缓慢推进、跟拍、横移或摇镜；确需定机位时使用克制手持微晃。
- 视图片空间选用前景遮挡、倒影、画中画或偏心构图。
- 在单段提示词中也先写前景/构图，再写动作；把视线、眨眼、嘴唇、头颈、肩膀、手指和重心变化拆成连续的小动作。
- 结尾加入：`人物与场景大小适配，人物与场景光影自然融合`。
- 结尾加入：`无音乐，保留与画面同步的现场音效`。
- 需要负面提示词时可使用：变形、扭曲、多余肢体、手指异常、面部模糊、动作卡顿、闪烁、身份漂移。

## MiniMax Hailuo

使用详细的多镜头描述，并让每个镜头都完整、具体、可执行。

- 按“镜头1、镜头2、镜头3……”展开，不要压缩成单一短句。
- 每个镜头包含：景别、方括号运镜指令、大光圈、浅景深、动作或微表情、可见元素的动态，不复述参考图的静态内容。
- 先写前景遮挡或特殊构图，再按时间顺序拆解动作；细化视线、眼睑、眉毛、嘴唇、下颌、头颈、肩膀、呼吸、手腕、手指、躯干重心和步态等可见动态，但不重新描述静态外观。
- 使用方括号运镜指令：`[推进]`、`[拉远]`、`[左摇]`、`[右移]`、`[跟随]`、`[变焦推近]`。尽量不用`[固定]`；必须使用时补充“手持微晃”。
- 必要时可组合两个相容指令，例如 `[推进，上摇]`；避免同时使用方向冲突的指令。
- 根据图片空间合理加入前景掠过、短暂遮挡、倒影、画中画或引导线构图。
- 让表情和情绪逐镜头递进，并保持人物身份、服装、道具、光线方向和空间位置连续。
- 结尾统一加入：`人物与场景大小适配，人物与场景光影自然融合；无音乐，保留与画面同步的现场音效`。

### 建议模板

```text
镜头1：[运镜指令] 景别，焦段，大光圈，浅景深；可选前景遮挡或特殊构图；动作起始，逐步写清可见五官、头颈、躯干与四肢的联动；画面内元素的动态。
镜头2：[运镜指令] 景别切换，焦段，大光圈，浅景深；特殊构图或镜头衔接；动作过渡、停顿与发展，按可见部位拆解。
镜头3：[运镜指令] 景别，焦段，大光圈，浅景深；可选前景或构图；动作收尾，写清五官、头颈和身体最终停留状态。
整体：人物与场景大小适配，人物与场景光影自然融合；无音乐，保留与画面同步的现场音效。
```

## MiniMax H3

- 使用清晰、可执行的自然语言；多镜头内容按“镜头1、镜头2……”或时间段组织，保持参考图中的人物、肤色、光线和空间连续。
- 只写动作表演、画面内元素的动态、镜头运动和声音；不复述图中主体、外貌、服装、环境、光线或氛围。
- 保持参考人物身份、肤色、痣、雀斑与疤痕，不凭空增加显著标记。
- 每个镜头优先使用推进、拉远、横移、跟随或摇镜；确需定机位时保留手持微晃。
- 视空间合理加入前景掠过、遮挡转场、反射、画中画或偏心构图。
- 在每个镜头内先写前景/构图，再按时间顺序写动作；把视线、眼睑、眉毛、嘴唇、下颌、头颈、肩膀、呼吸、手腕、手指、重心和步态拆成可执行的连续细节。
- 真人写实任务必须按 [真人皮肤质感限定](photoreal-skin.md) 装配皮肤约束：特写与近景完整写入四项皮肤锚点，中景至少两项，远景只保留真实肤色与非塑料质感。
- 把完整皮肤限定放在全局视觉约束中声明一次；新的脸部特写可再次简短强调毛孔微纹理、SSS 暖透感与仅 T 区微油，避免逐镜头机械重复整段。
- 使用 45° 柔和侧主光与轻微逆光呈现皮肤层次；避免硬正面光、顶平光和无阴影的美颜棚拍光。
- 负面提示词必须排除塑料人偶皮肤、蜡像、磨皮美颜、3D 渲染脸、全脸油光、无纹理面具脸和数学式完美对称。
- 结尾写明无音乐，只保留与画面动作同步的现场音效。

### 真人写实建议结构

```text
镜头/时间段：景别、运镜与摄影参数；可选前景遮挡或特殊构图；按时间顺序拆解可见五官、头颈、躯干与四肢动作；画面内动态。
整体限定：保持参考图一致；人物与场景大小适配，人物与场景光影自然融合；按景别应用真人皮肤技术限定；无音乐，有同步现场音效。
避免：塑料、蜡像、磨皮、3D 渲染、全脸油光、身份或肤色漂移。
```
