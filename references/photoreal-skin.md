# 真人皮肤质感限定

仅在当前模型为 **Seedance 2.0** 或 **MiniMax H3**，且用户要求真人、写实、实拍、生活感或自然人像时应用。不要用于动画、漫剧、插画或明确的非写实风格。

## 装配规则

- 特写、近景、情绪独白：完整写入 SSS、毛孔、T 区微油、绒毛与微汗四项。
- 中景：至少选择两项与画面可见范围相符的皮肤细节，优先毛孔微纹理和自然肤色不均。
- 全景、远景：只保留“真实人类皮肤、自然肤色和非塑料质感”，不要声称镜头能看见毛孔或面部绒毛。
- 多镜头人物：在整体视觉限定中完整声明一次；遇到新的脸部特写时再次简短强调，保持肤色、纹理和光泽连续。
- 参考图生成：保持图中身份、肤色、痣、雀斑与疤痕，不凭空增加显著标记；皮肤段只写技术质感、光照响应和动态细节，不复述人物外貌。

## 四项皮肤锚点

1. **SSS 暖透感**：耳缘与鼻缘呈现克制的次表面散射和薄皮暖透光，不要全脸发红或自发光。
2. **毛孔与微纹理**：可见毛孔、自然皮肤微纹理和轻微肤色不均，不要磨皮或锐化过度。
3. **仅 T 区微油**：只在额头与鼻梁保留轻微自然皮脂光泽，面颊和全脸不能油亮。
4. **绒毛与微汗**：颧骨细小绒毛在侧光中可见，皮肤带克制的微汗；不要水珠覆盖全脸。

同时选择至少两项自然不完美：淡雀斑、细小痣或浅疤、轻微瑕疵、肤色不均、细纹、面部轻微不对称。不要为了“真实”把人物写成病态、脏污或衰老，除非剧情要求。

## 打光限定

使用 45° 柔和侧主光和轻微逆光，让耳缘、鼻缘的 SSS 与面部微纹理自然显形。避免硬正面光、顶平光和均匀无阴影的美颜棚拍光。
